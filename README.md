# 🦆 Ducky

**Your tiny desktop companion.**

一只轻巧、贴心的小鸭子，让电脑上的日常操作变得简单一点。

## 👋 Hello, I'm Ducky!

你好呀，我是 Ducky！

我是一款为 Windows 打造的轻量级桌面效率工具。

平时，我会安安静静地待在系统托盘里，不占用你的注意力。当你需要帮助时，我会尽可能快速、自然地完成那些琐碎的小事。

我希望让你少一些重复操作，多一点顺畅自在。

## ✨ What Can I Do?

### 🎙️ Voice Input · 语音输入

有时候，说出来比打出来容易得多。

按下快捷键，直接说出你想输入的内容，Ducky 会通过语音识别服务将它转换为文字，并输入到当前正在使用的应用程序中。

无论是聊天、写作，还是记录突然冒出来的想法，都可以更轻松。

### 📋 Clipboard Sync · 剪贴板同步

复制一次，让内容自由流转。

Ducky 可以在不同设备之间同步剪贴板，让文字的传递变得自然、简单。

不必为了发送一段文字，专门打开聊天软件或者文件传输工具。

### 🪶 Lightweight & Unobtrusive · 轻巧而安静

我喜欢待在你身边，但不会一直打扰你。

Ducky 追求轻量的资源占用、快捷的响应速度和简洁的交互体验。

只有在你需要的时候，我才会出现。

## 🌱 There's More to Come

Ducky 还很年轻。

语音输入和剪贴板同步只是旅程的开始。未来，我会继续探索更多有趣、实用的小功能，让电脑更懂你的习惯，也让人与设备之间的交互更加自然。

我不想成为一个塞满按钮的庞大工具箱。

我更希望，每一个新功能都能让你觉得：

**「咦，这个小东西还挺好用的嘛！」**

## 🚧 Project Status

Ducky 正在积极开发中。

目前的开发重点是语音输入、跨设备剪贴板同步以及统一的桌面交互体验。

更多功能将在后续版本中逐步加入。
